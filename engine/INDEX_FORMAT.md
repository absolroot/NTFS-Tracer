# NTFS Tracer SQLite 색인 읽기

Rust 엔진 0.4.0부터 모든 모듈이 같은 방식으로 출력을 식별한다. 입력 파일과 새 출력 경로를 CLI에 전달하며, 성공 종료한 뒤 읽기 전용으로 연다. GUI는 임시 파일에 생성한 뒤 원본 SHA-256을 대조하고 완성된 파일을 캐시에 게시한다.

| CLI 모드 | `artifact_meta.module` | `PRAGMA user_version` | 기존 요약 테이블 |
|---|---|---:|---|
| 기본 USN 저널 | `usn` | 3 | `summary` |
| `carve` | `usn_carve` | 3 | `summary` |
| `mft` | `mft` | 1 | `mft_summary` |
| `logfile` | `ntfs_log` | 2 | `tx_summary` |
| `logcarve` | `ntfs_log_carve` | 1 | `carve_summary` |

1. `PRAGMA application_id`가 `0x4A44534B`(JDSK)인지 확인한다.
2. `SELECT module, schema_version, engine_version, source_sha256, source_size FROM artifact_meta`로 한 행을 읽는다. 모듈 종류와 스키마 버전을 **함께** 비교하고, 스키마 버전이 `user_version`과 같은지 확인한다. 엔진 버전은 결과를 생성한 실행 파일의 버전이다.
3. 원본 해시와 바이트 수를 모듈별 요약의 `hash`, `bytes`와 대조한다. 원본에 다시 연결할 때에는 실제 파일에서 계산한 SHA-256도 대조한다. 이러한 검사는 서로 다른 수집본이 같은 볼륨에서 왔는지까지 판정하지는 못한다.
4. 이전 캐시는 `application_id=0`이며 `artifact_meta`가 없다. 기존 USN 형식 2, MFT 및 로그 계열 형식 1은 원래 모듈을 알고 있을 때 해당 요약과 원본 해시를 검증해 읽을 수 있다. 구형 USN 일반 분석과 카빙은 테이블 형태가 같아 테이블 이름으로 구별할 수 없다.

## 모듈 사이에서 근거를 전달할 때

- USN의 `records.pos`, `size`는 해시를 계산한 **추출 파일**에서의 시작 위치와 길이(바이트)다. 이름 길이는 UTF-16LE 바이트 수이며, `stamp`는 원본 FILETIME이다. V4의 시각과 이름은 NULL일 수 있다. 추출된 스트림의 위치와 디스크 이미지의 물리 주소는 구분한다.
- 파일·부모 식별자는 BLOB이다. V2의 8바이트 참조에는 항목 번호와 사용 회차가 함께 들어 있다. V3/V4의 16바이트 참조는 원래 길이를 유지한다. 서로 다른 수집본의 같은 값이 같은 파일을 보장하지 않는다.
- `warnings`와 `segment`는 손상되거나 해석하지 못한 구간 경계를 보존한다. 카빙 결과의 위치는 카빙한 입력에서의 위치다. 카빙 후보에는 일반 저널과 다른 출처를 남겨야 한다.
- 트랜잭션의 원본 헤더 위치와 섹터를 복원해 이어 붙인 Redo·Undo 데이터 내부의 상대 위치는 서로 다르다. `ntfs_log` 2는 트랜잭션의 시각 변경 근거를 원본에 연결하는 바이트 위치를 추가한다. 타임라인에 사용할 시각의 출처와 단위는 모듈별로 확인한다.

새 소비자는 지원하지 않는 모듈·버전을 발견하면 해당 출력을 열기 전에 사용자에게 이유를 알린다. 조사 메모나 북마크는 재생성할 수 있는 엔진 색인 밖에 저장하고, 원본 해시와 기록 위치를 참조하는 방식이 적합하다.

## 색인 없이 USN CSV 내보내기

추출한 `$J`에서 USN V2 레코드를 원본 순서대로 읽어 UTF-8 CSV 13열을 저장한다. 파일과 상위 폴더 참조는 항목 번호와 사용 회차로 나누고, 시각은 UTC로 표시한다. `OffsetToData`는 입력 파일의 바이트 위치다. 이 명령은 MFT를 연결하지 않으므로 `ParentPath`는 비어 있다.

지원하지 않는 레코드 버전을 만나면 출력을 게시하지 않고 오류를 반환한다. 일부 손상된 바이트를 건너뛴 경우에는 건너뛴 바이트 수를 표준 오류에 기록한다. 기존 출력 파일은 덮어쓰지 않는다.
